# wayfinding-audit CLI

Generated by `tooling/build.ts --format cli`. The build copies `lib/` into `src/lib/` next to this file, so the CLI has no runtime dependencies and no network access.

```
npm install
npx tsc
node bin/audit.js check directions.txt --locale fr --orientation-invariance
node bin/audit.js rewrite directions.txt --landmarks "the red church, the fuel station" --anchor "watch hand:left" --facing "the red church" --stress
node bin/audit.js refs email.txt --locale es --landmarks landmarks.json
node bin/audit.js query --center 38.861,-77.362 --radius 120 > query.overpassql
```

Exit code 1 from `check` means at least one error-level finding, which makes it usable as a CI gate for signage copy and direction sets.
